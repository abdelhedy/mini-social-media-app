# mini-social-media-app
A lightweight social media application built with Spring Boot and MongoDB. This app allows users to manage accounts, create and view posts, follow/unfollow other users, and engage through comments and likes.

---

## Features

- **User Management**: Create, update, delete user accounts.
- **Post Management**: Create, edit, delete, and view posts.
- **Followers/Following System**: Manage user connections.
- **Likes & Comments**: Engage with posts.
- **RESTful API**: Interact via API endpoints.

---

## Tech Stack

- **Backend**: Java, Spring Boot
- **Database**: MongoDB
- **Version Control**: Git, GitHub
- **Other Tools**: Maven (for dependency management)

---
